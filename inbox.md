# Idea inbox

This is a bounded pressure test. The July 14 portfolio audit reopened the earlier decision once, after new source repositories and current local prior art materially changed the evidence. All entries are unresearched unless promoted to [`idea.md`](idea.md).

## Strategic generation frame

Generate at the intersection of:

1. **Official demand:** Codex leverage, AI-native product, developer tooling, eval/reliability, domain agent, or one of the four global tracks.
2. **Unfair start:** evidence-first engineering, Philippine entity/data experience, BLEAD source discovery, university context, and a two-person product/demo team.
3. **Judge-visible proof:** red-to-green test, source receipt, abstention, deterministic diff, replay, or observable state change.

An idea that has only two of the three stays in the inbox.

## Promotion gate

An inbox entry may challenge the current finalist set only when all are true:

- it fits an official category and uses GPT-5.6 and Codex materially;
- one real user and one costly observable failure are named;
- its complete demo atom fits in one sentence;
- two people can build the core in at most three productive hours;
- the data and media rights are clear;
- the nearest three alternatives have been researched;
- it scores at least as well as a finalist after pressure from current comparables, or removes a fatal blocker with lower completion risk;
- it is a distinct product, not a feature mutation pretending to be another option;
- it passes the chat-substitution gate (added July 18): a judge asking "why not just paste this into ChatGPT/deep research?" gets a structural answer — data the model does not have, a deterministic receipt a chat cannot emit, embedding in an existing workflow (no new signup), or state maintained across time. "Our prompt is good" is not an answer.

The first two sweeps overcommitted to source-change regression. The third sweep audited all 49 Easyresume project descriptions, TunnelMind's actual live state, VANTAGE's Slack export, and 686 current AppBuildersPH app cards. It reopened the decision and promoted three distinct finalists. Build Receipt remains the low-risk fallback.
